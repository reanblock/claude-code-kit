# User Preferences

## Communication
- Keep answers short, clear, and concise. Lead with the direct answer.
- Don't pre-explain or add lengthy preamble; I'll ask for more detail if I need it.
- Ask questions if anything is unclear or ambiguous rather than guessing.

## Python
- Use `uv` for environment and package management (e.g. `uv add`, `uv run`).
- Prefer `uv` over `pip`, `poetry`, or `virtualenv`.

## JavaScript / TypeScript
- Prefer `yarn` for package management (`yarn add`, `yarn install`)

## Testing
- For any code change, add a test that covers the change.
- If no test framework is set up, ask which one to use before adding tests.
